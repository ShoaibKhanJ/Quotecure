# QuoteCure ✨

A modern, premium quote web application designed to deliver daily motivation, discipline, mindset, and wisdom through curated quotes.

---

## 🚀 Features

- 📌 Quote of the Day (auto-generated daily)
- 🔍 Smart search (by text, author, mood, domain)
- 🎯 Category filtering (Mood / Domain / Writer)
- ❤️ Save favorite quotes (localStorage)
- 🌙 Dark / Light mode toggle
- 📋 One-click copy quotes
- 📤 Share quotes easily
- ⚡ Fast, lightweight, no backend required
